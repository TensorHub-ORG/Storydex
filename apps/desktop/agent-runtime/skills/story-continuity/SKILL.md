# Story Continuity

1. Separate project canon, author notes, inferences, and what each viewpoint character can know.
2. Check location, injuries, possessions, relationships, unresolved causes, story time, active outlines, planted payoffs, and locked facts.
3. Trace uncertain variables to chapter or project-file sources. Mark unsupported memory stale instead of inventing a resolution.
4. Respect flashback time separately from the main current time. Do not leak later outline material into an earlier viewpoint.
5. Resolve conflicts by priority: locked fact, current project file, later high-priority preset, established chapter evidence, conversational recall.
6. Return concise drafting constraints or a structured state delta; do not produce a second version of the scene unless the author asks.
