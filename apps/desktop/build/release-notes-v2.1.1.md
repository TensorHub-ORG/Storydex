# Storydex v2.1.1

本次更新修复 Agent 工具误拦、任务续接丢失授权和计划模式退出问题，并精简 Windows 验证与发布流程。

## 使用体验

- “新建角色卡”等写入请求能正确识别；“继续”“确认”“按刚才的方案执行”可以续接本版本记录的任务授权，保持原有目标和目录范围。
- 角色卡、世界书等任务不再因为关键词生成的工具白名单误拦编辑、补丁、检索或向用户提问。明确只读、目录范围及执行审批继续生效。
- 退出计划模式后刷新工具列表并恢复原任务能力；原本只读的任务仍保持只读，退出状态会同步到后续会话。
- 包含近期知识图谱节点归属、关系语义和分页修复。

## 发布与维护

- Agent 运行时、Tauri 外壳和打包脚本分别执行检查，更新官网版本链接不会触发无关平台测试。
- 相同提交的成功组件检查可以在开发分支、主分支和发布之间复用；检查缺失或无法获取证据时自动补跑。
- 发布保留依赖审计、源码身份和最终产物校验，运行时只在打包阶段构建一次。

## 获取更新

- Windows x64 安装包：`StorydexSetup-x64-2.1.1.exe`。
- 便携包：`Storydex-win-portable.zip`。
- 支持应用内更新，也可从 GitHub Releases 下载完整安装包。
