# Storydex Android v0.1.0（测试）

Storydex Android 首个公开测试版本，将移动端体验定义为“可持续推进的角色扮演小说”。

## 主要能力

- 剧情、剧情旁白、独立 Agent 三种手动切换模式。
- 沉浸、叙事、自由三档剧情控制，并在每轮开始进行 OOC 意图判断。
- 故事项目目录、剧情片段分组、最近剧情续接与项目知识读取。
- 可配置的剧情片段字数和推理强度。
- 询问、自动、放行三档操作权限，默认放行。
- 五套即时生效的主题配色和统一的 Storydex 品牌图标。
- 半屏 Agent 执行瀑布流，内容超出时独立滚动，不压缩工具卡片。

## 安装信息

- 文件：`Storydex-Android-arm64-v0.1.0.apk`
- 架构：ARM64 (`arm64-v8a`)
- 最低系统：Android 7.0（API 24）
- 当前状态：测试版
