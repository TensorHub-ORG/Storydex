# 普通 Agent 执行与回复可靠性核对

日期：2026-10-28，基于已推送的 `f978dd7` 继续核对。本文新增修改留在本地，未提交、未推送；未运行 Playwright、E2E 或付费模型。

后续 pi 已独立完成普通聊天入口的真实复测，见仓库本地 `output/playwright/pi-agent-nl-20261028/REPORT.md`。下文单独记录复测结论和随后追加的生命周期修复，避免将 pi 的测试结果算作追加补丁的浏览器验证。

## 已确认的问题

- 普通任务提示已有工具使用、目录、权限及多文件要求，但没有明确写作工作台中“写下一章”默认通过文件工具交付。模型仍可能把它理解为聊天创作；代码没有足够证据将每次这种输出归为解析错误。
- 直接章节生成会检查截断，但普通 Agent 原先忽略供应商结束原因；无工具调用就返回成功，空回复和供应商标记的不完整回复也可能走这个分支。
- 普通 Agent 达到工具轮数上限后返回 `Ok` 并发出 `TurnCompleted`，把尚未完成的执行显示为完成。
- 折叠工具摘要将失败、未完成的调用也计入“修改 N 个文件”，并把工具调用次数误当成文件数。

## 本次调整

- 在现有提示中明确：创作、续写、改稿和整理项目内容默认落实到项目文件；讨论、点评、示例及明确要求仅聊天输出时不写。文件路径由模型结合项目结构选择；操作前简短说明目标，最后依据真实工具结果报告。工作台和无自定义提示的 bridge 入口共用这段约定，移除 fallback 中“一次修改后停止”的旧描述。
- 正常、非空的直接回复继续允许；不新增意图分类器、强制完成工具、正文识别器或自动把聊天正文落盘的逻辑。
- 空回复且无工具调用时，在现有工具循环内给一次纠正提示；再次为空则报告未完成。只有异常空回复可能多一次模型调用，且仍受原工具轮数上限约束；已成功的工具结果保留在上下文中。
- 供应商明确标记长度截断，或状态为 incomplete/failed/cancelled 时，保留已返回文字和用量，整批未执行的工具不再执行，不发出完成事件。会话中记录未执行结果和中断说明，便于之后继续。
- 轮数耗尽返回现有 `ToolRoundLimit` 错误，保留已执行操作；不再报告完成。
- 工具摘要按真实状态分别显示成功、失败、未完成的调用次数；底部“已完成”改为“本轮结束”，不以消息结束代替用户任务验收。

## 验证及边界

- engine 的 14 项 Agent 聚焦测试通过，含正常文本回复、空回复恢复且不重放成功工具、连续空回复终止、各供应商截断标记、截断工具不执行、轮数上限，以及现有工具/插话/压缩回归。
- agentd chat 的 24 项聚焦测试通过；bridge 失败会话保存测试通过。engine、agentd、bridge Clippy 及格式检查通过。
- 前端 AgentPanel 39 项通过，包含失败调用不能冒充成功修改、同文件多次编辑不冒充多个文件；类型检查通过。
- 提示与程序异常处理可以减少问题，不能证明真实模型已经稳定理解所有写作说法。尤其是“正常非空正文但没有调用工具”，仍由模型结合任务约定判断，未强制拦截讨论型回复。
- 不新增真实模型调用做自评、意图裁定或质量 Judge。未证明字数命中率、文学质量或长篇事实连续性。

## pi 真实复测与断连修复

- 普通聊天的写下一章、续写、指定句修改均有实际文件变更证据；讨论、点评、仅聊天示例没有写入。拒绝/取消审批后未绕过，失败工具没有显示成写入成功。
- 续写首次请求停在澄清问题；测试脚本没有回答，关闭页面后执行仍保持 active，阻止切换项目。因此成功的续写样本来自另一干净项目的第二次请求，不能记成首次无干预通过。
- 空回复、截断、轮数耗尽的成功验证来自 replay 注入，只覆盖 Agent 循环层，没有覆盖真实供应商 HTTP/SSE 的结束标记解析。
- O1 是已确认的生命周期缺口：原代码已有发送事件失败时的 `client_disconnected` 取消逻辑，但等待用户回答期间没有新事件，因此没有发现客户端已断开。此次在 `run_chat_with_timeout` 中直接监听响应通道关闭，再等待原有取消和会话收尾完成，释放执行占用并暂停后续消息。未增加用户答复时限，连接仍在时继续等待。
- 追加两项后端路由测试，覆盖未设超时及设有超时的静默等待断连、响应流仍在时继续等待、正常答复、执行及后续消息占用释放、既有正文保留、迟到答复失效。不启动浏览器、不调用真实模型。chat 模块共 26 项通过，agentd Clippy、格式及差异检查通过。
- 后续 pi 连续写作实测已通过断连补丁的浏览器验收：等待审批时关页自动以 `client_disconnected` 取消，重开后切项目并完成新任务，未手工 stop；保持连接等待 30 秒后回答两问，正常编辑完成、未误取消。见本地 `output/playwright/pi-writing-multiturn-20261028/REPORT.md`。该轮新发现的长输出断流、章节索引和图谱问题另见[当前情况交接](current-status-20261028.md)。
- 非 Git 项目的 `+0 -0` 展示和模型段落计数措辞仍保留为小问题；本机 Python stub 与 PowerShell 中文路径失败不作为本轮已修复项。报告中的 `--coomi-home` 斜杠形式观察也尚未独立复现。
